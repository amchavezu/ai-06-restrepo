1. Write the technology-constrained case $I^*=I<\widetilde I$ and set $dN=0$.
2. Copy the paper's wage decomposition:

   \[
   d\ln W=d\ln Y\vert_{K,L}-(1-s_L)\frac{\Lambda_I}{\widehat\sigma+\varepsilon_L}\,dI.
   \]

3. Substitute the productivity term:

   \[
   \frac{d\ln Y\vert_{K,L}}{dI}
   =\frac{B^{\widehat\sigma-1}}{1-\widehat\sigma}
   \left[\left(\frac{W}{\gamma(I^*)}\right)^{1-\widehat\sigma}-R^{1-\widehat\sigma}\right].
   \]

4. Label the first term “productivity” and the second “displacement.” Derive the inequality $P_I>D_I$ for a wage increase.
