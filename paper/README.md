```bash
curl -L -o paper/acemoglu-restrepo-2017-race-machine-man.pdf \
  https://www.nber.org/system/files/working_papers/w22252/w22252.pdf
```

The published AER article reverses the order of “Machine” and “Man” in the title and uses different pagination. This repository cites the NBER proposition numbering used by the required Lean run.
